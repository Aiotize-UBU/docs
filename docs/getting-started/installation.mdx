## Prerequisites

- Node.js 18 or later
- Git

## Clone the repository

```bash
git clone https://github.com/Aiotize-UBU/docs.git
cd docs
```

## Install the Mintlify CLI

```bash
npm i -g mint
```

## Preview locally

Run the dev server from the repo root:

```bash
mint dev
```

The site is served at `http://localhost:3000` with hot reload.

## Validate before pushing

```bash
mint validate
mint broken-links
```
